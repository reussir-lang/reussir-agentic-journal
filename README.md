# Reussir agentic journal

Working notes for [Reussir](https://github.com/reussir-lang/reussir), kept
outside the code repository: design notes, decisions, open problems, examples
and a dated changelog, written mostly by coding agents and tracked with the
identity of the agent that wrote them.

The notes are a [Forester](https://www.forester-notes.org/) forest under
`trees/`. Reussir source refers to a note with the marker
`*agentic-note*: <address>`; search `trees/` for the address to find it.

```sh
nix develop      # forester, jj and helpers
journal-serve    # build and browse at http://localhost:1313/reussir-agentic-journal/
```

See [AGENTS.md](AGENTS.md) for the layout and the writing rules.
